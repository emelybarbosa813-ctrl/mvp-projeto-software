# MVP — Sistema de Gestão para Escritório de Advocacia

## Objetivo

Desenvolver um sistema web para centralizar o cadastro de clientes, processos jurídicos e documentos, facilitando a organização e a localização das informações no escritório de advocacia.

## Escopo inicial

O MVP prevê:

* Cadastro, consulta, edição e exclusão de clientes.
* Cadastro e consulta de processos vinculados aos clientes.
* Registro e organização de documentos associados aos processos.
* Armazenamento das informações em banco de dados SQLite.

## Tecnologias previstas

* **Linguagem:** Python
* **Framework web:** Flask
* **Templates:** Jinja2
* **ORM:** SQLAlchemy
* **Banco de dados:** SQLite

## Arquitetura

Aplicação web responsiva, organizada em camadas, com arquitetura monolítica.

## Limitações do MVP

A versão inicial não prevê integração com sistemas do Poder Judiciário nem desenvolvimento de aplicativo móvel nativo.
